## 一、原始数据源（S 编号）

### S-1 ｜ 广州大众点评 POI 全量快照

| 项 | 内容 |
| --- | --- |
| 文件 | `202604广州.parquet` |
| 体量 | 195,900 行 × 38 列 |
| 时点 | `vintage_yyyymm = 202604`（2026 年 4 月），单期快照 |
| 来源标记 | `source_file = 202604广州.xlsx`，`vintage_basis = sheet_name` |
| 关键字段 | 店铺名称、品牌、行政区、商圈、地址、经度、纬度、平均消费、店铺评分、子评分、评论数、营业时间、营业状态、推荐菜、点评榜单、特色服务、服务设施、大类/中类/小类、店铺链接 |
| 主键 | `店铺id` |

**筛选口径**

- 潮发门店：`品牌 = '潮发潮汕牛肉店'` → **73 家**
  （注：库内另有 16 个含"潮发"字样但无关的品牌，如潮发汤粉世家、潮发烧鹅店、潮发粮油店等，全部排除）
- 品类：`小类 = '潮汕牛肉火锅'` → **982 家**
- 直接连锁竞品：`品牌 IN ('八合里潮汕鲜牛肉火锅','陈记顺和潮汕牛肉火锅','海银海记潮汕牛肉火锅','九亩地牛肉火锅')`

**子评分解析**（主报告 2.3 节）

```sql
try_cast(regexp_extract(子评分,'口味:([0-9.]+)',1) as double) AS s_taste,
try_cast(regexp_extract(子评分,'环境:([0-9.]+)',1) as double) AS s_env,
try_cast(regexp_extract(子评分,'服务:([0-9.]+)',1) as double) AS s_svc,
try_cast(regexp_extract(子评分,'食材:([0-9.]+)',1) as double) AS s_food
```

**已知偏差**
- 单期快照，无时间序列，不能判断趋势。
- 评论数是**累计存量**，与开业年限强相关，新店系统性偏低。
- 平均消费为平台估算值，非实际客单。品类内 192 家为 0 或空值，计算中位时已排除。
- 「推荐菜」由用户评价聚合生成，**不是门店菜单，也不是销量**。
- 「特色服务」「服务设施」为可选字段，品类内缺失率分别为 72.5%（712/982）与 63.4%（623/982）；潮发内为 53.4%（39/73）与 38.4%（28/73）。所有基于这两个字段的占比，**分母均为该字段非空的门店数**，已在正文注明。

### S-2 ｜ 十店启动项目数据包

| 项 | 内容 |
| --- | --- |
| 文件 | `潮发十店启动项目.zip` |
| 核心库 | `competition.duckdb`（表：`origins` `classified` `classified_flagged` `neighbors` `neighbors_5km` `cannibal_3km` `rings_summary` `store_ops` `_check`） |
| 重建脚本 | `build.sql` |
| 前序结论 | `讨论稿.md`、`README.md` |
| 底表 CSV | `全市/`（7 个）、`周边/`（4 个）、`十店/`（2 个） |

**`store_ops` 口径**（主报告 2.6.2、3.4 节）

| 字段 | 含义 |
| --- | --- |
| `ticket_n` / `ticket_due` | 2026-05-01~07-31 已结账小票张数／应收金额（元） |
| `dine_n` / `dine_pct` | 堂食票数／堂食占比 |
| `dine_med` / `party` | 堂食桌均中位（元）／桌均人数 |
| `card_n` `card_due` `card_users` `card_ticket_pct` | 充值卡核销笔数／应收／人数／占小票张数比 |
| `poi_*` | 关联的点评 POI 字段（仅 7 家广州店有值） |

**派生计算式**
- 票均 = `ticket_due / ticket_n`
- 日均票 = `ticket_n / 92`（2026-05-01 至 07-31 共 92 天）
- 日均应收 = `ticket_due / 92`

**圈层口径**（`rings_summary`，主报告 2.7、3.4 节）
- 距离：WGS84 球面米；**环带内环含在外环内**（3km 含 1km 含 500m）
- `is_chaofa`：品牌 = 潮发潮汕牛肉店
- `is_direct`：小类 = 潮汕牛肉火锅，或品牌名含八合里／陈记顺和／海记／九亩地等具名连锁
- `is_reference`：牛羊肉火锅、桐坑牛肉、火锅人均 70–130、椰子鸡、打边炉、潮汕菜且人均≥50、推荐菜含潮汕/手切牛肉
- 计数**含本店**

**已知偏差**
- 十店中仅 7 家在广州；千灯湖（佛山）、万象食家（深圳）、万象滨海（东莞）本库无对应城市点评，圈层全部为 0（`_check.out_city_neighbors_5km = 1`，仅一条广佛交界噪声）。三店 GPS 为商场公开坐标，非点评店点。
- **无面积、座位数、租金、商场抽成、开业日期、成本与利润。** 这是主报告所有门店间横向比较的最大限制。
- 应收 ≠ 营业额（未含税费口径说明、未拆渠道）。

### S-3 ｜ 充值卡消费记录（用户画像更新版）

| 项 | 内容 |
| --- | --- |
| 文件 | `潮发十家门店充值卡消费记录_用户画像更新版.xlsx`（单表 `用户账单`） |
| 体量 | 6,292 行 × 15 列 |
| 时间范围 | 2026-05-01 11:25:36 ~ 2026-07-31 23:58:43 |
| 交易类型 | 全部为「就餐消费」，内容全部为「食堂点餐」 |
| 字段 | 用户编号、交易类型、充值卡金额、内容、订单号、操作日期、核销门店、关联会员卡、关联管理员、订单流水、订单优免金额、订单应收、会员类型、生日、性别 |

**派生计算式**
- 日期 = `操作日期` 去掉前导单引号后解析
- 时段桶：午市 11–15 / 下午茶 15–17 / 晚市 17–22 / 夜宵 22–06 / 其他
- 周末 = `dayofweek >= 4`（含周五）
- 门店 = 从 `核销门店` 中提取全角括号内文字
- 折让率 = `订单优免金额 / (订单优免金额 + 订单应收)`
- 年龄 = `2026 − 生日年份`

**已知偏差（重要）**
- 核销笔数仅占十店小票 **1.9%–4.5%**，是会员切片，**不能当门店营业额或客群代表**。
- 黑金一档占 60.8% 笔数（3,824/6,292），整体分布被该群体主导。
- **生日字段质量差**：475 笔缺失（全部为「游客」），147 笔出生年 >2010（含 2026 年），年龄结论有噪声。
- 「游客」475 笔无性别、无生日，性别占比计算时作为缺失处理。
- 只有核销侧，**无充值额、赠送额、过期额、跨店核销标记**。

## 三、口径与判断的分级标注

主报告中的每条结论已标注证据强度，对应关系如下：

| 标记 | 含义 | 判定规则 |
| --- | --- | --- |
| 【A】 | 强证据 | 三层数据（S-1/S-2/S-3）交叉验证，或 S-1 大样本（n≥73）单调支持 |
| 【B】 | 中证据 | 单层数据支持，方向可信，幅度不可信 |
| 【C】 | 假设 | 逻辑推演或行业常识，本次数据无法验证，需先小样本试点 |
| 〔框架设计，非数据结论〕 | 方法论 | 不来自数据，来自分析框架选择 |
| 〔推理为分析判断〕 | 判断 | 数据为真，但从数据到结论之间有一步分析者的推断 |

**明确标注为"本次数据不支持"的三处**（防止被误引用）：

1. **"挂明档能提升食材分"** —— 不成立。15 家有明厨亮灶标签店食材均分 4.727，39 家无标签店 4.708，差 0.019。〔S-1｜T2〕
2. **"24 小时导致应收 +46.5%"** —— 不成立。只能说"24 小时店与高应收同现"，n=2 vs n=5，且缺 D-14（面积/座位/租金/开业年限）。〔S-2｜T6〕
3. **"自网密集造成蚕食"** —— 不成立，且数据方向相反（3km 内 6 家以上同网店的门店，评论中位 2,950，远高于 0 家组的 642）。判定蚕食需 D-06 跨店会员重叠。〔S-1｜T2〕
