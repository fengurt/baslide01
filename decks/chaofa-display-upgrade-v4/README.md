## 核心结论

1. **单点主菜在 ¥109–157「招牌利润带」零供给。** 价格序列止于雪花肉半斤 ¥105，下一档为至尊七宝 ¥268，中间 163 元区间的 46 个 SKU 全部是套餐。陈家祠与东方新世界两店的「主」角色分布完全相同（5/15/2/9/0/1），属品牌层菜单结构问题。
2. **四类高毛利商品已在十店全量销售，合计 233.0 万元，点评心智覆盖率为 0。** 现烤串 79.6 万、鸭屎香柠檬茶 63.4 万、至尊七宝 48.2 万、F1 鲜和牛 41.9 万。菜品更新的第一优先级是建立陈列位，而非研发新品。
3. **菜单宽度远超认知容量。** 单店在架 214 个 SKU，贡献 80% 销售额的仅 30 个，顾客心智货架 11.7 个。839/2,144 条 SKU 记录三个月销售额不足 1,000 元。
4. **饮品结构严重失衡。** 64 款工业采购饮料合计 51.4 万元，3 款自制饮品 63.7 万元，单 SKU 产出相差 26 倍。
5. **会员价值由到店次数驱动。** 四个价值分层的人均单次实收在 ¥245–312 之间波动，差异全部来自订单次数中位（1/3/4/5）。42.8% 的会员三个月仅到店一次。
